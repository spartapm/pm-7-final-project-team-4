충돌 시 **화면설계서(피그마) 우선**.

## 공통

- Web: `web_bg.png` cover, 중앙 390×844 휴대폰 프레임(라운드·섀도). 브라우저 크기와 무관하게 내부 UI 고정
- 390px 미만 Web: 390×844 유지, 가로 스크롤
- 모바일: 프레임·`web_bg` 없음, 전체 화면
- 헤더·탭바는 콘텐츠 스크롤과 분리, 상위 레이어

## 온보딩

- 나이: `나이 (선택)` → 밑줄 입력 → `살` 한 행, 간격 8px, 라벨 바로 우측
- 여정 버튼 라벨: Jua 16px
- 완료하기: 박스 제거, Heading 1 텍스트, fill `#000` / stroke `#FFF`

## 홈

- 슬롯 5개, TO-BE 좌표(390×844). 빈 칸은 1번(빈 원)
- 글만: 2번(`footprit_icon.png`). 사진 포함: 3번
- 모바일: `home_bg_*_wide.png` cover + `home_bg_*_road.png` 가로 중앙. 슬롯은 로드 기준

## 리스트

- `+` 58×58, 스크롤과 무관 고정. 탭바보다 아래 레이어
- 우측 19px, 탭바 상단에서 16px 위
- 완료 시 `기록을 찾을 수 없어요` 화면을 거치지 않음. List-03-01/02로 바로 분기
- 모달 뒤 List-02 입력값 유지

## 메모리

- 정렬: 사용자 선택 일자(`m.date`). 0~1장이면 버튼 숨김. 배경 `#FBF6EF`
- 삭제 즉시 목록에서 제거
- 저장하고 나가기 검증: 빈 필드의 라벨 옆에만 인라인

## 프로필 / 프로필 수정

- `profile_wings.png` 교체본 적용. 원 지름은 생전과 동일, 날개 전체 노출
- 모드 전환: 로딩 중 문구·배경은 변경 전 상태 고정. 모달이 닫힌 뒤에만 전환 화면 노출
- 기본 이미지 `profile_camera_icon.png`. 사진 등록 시 `camera_icon.png` 우측 하단
- `기본 프로필로 변경`은 프로필 영역 하단 우측, Jua 12 / `#6F483A`
- 나이 필드 온보딩과 동일 배치
- Profile-02 탭바 미표시
- Profile-02는 원형 사진/카메라만. 날개는 Profile-01 사후에만

## 1.3 대비 하지 않는 것

- 390 미만 웹 가로 스크롤: 좁은 창은 폭만 줄임
- 짧은 웹에서 844 아래 잘림: 폰 높이 고정 유지
- 메모리 “완료 날짜” 전용 필드: 정책서는 사용자 선택 일자. 정렬은 `m.date`
- 옛 홈 390 배경 파일 삭제: 유지
- RN 화면 인벤토리: 웹만
